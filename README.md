# TASHwill Audio Project 

A continuous state console menu architecture implemented in Python to manage development pipelines.

## Technical Framework
- **State Management:** Uses an active local Dictionary structure to track project key-value parameters.
- **Runtime Persistence:** Employs an infinite `while` control loop structure to maintain application execution lifecycle.
- **Modular Design:** Segregates application responsibilities into distinct functional code blocks (`def`).
